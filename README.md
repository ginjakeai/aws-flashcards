# CLF単語帳

AWS Certified Cloud Practitioner 向けの一問一答単語帳です。iPhoneのホーム画面に追加すると、オフラインでも使えます。

## 使い方

1. iPhoneのSafariでGitHub PagesのURLを開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動（初回以降は通信なしで動きます）

## 単語データ

- `words.csv`（名称・分類・説明文・章・トピックの5列）を差し替えると、内蔵の単語リストが変わります
- 出題範囲は「分類」「章」「トピック」を組み合わせて絞り込めます
- アプリの「単語一覧」や学習中のカードから用語を編集・追加・削除でき、「データ」タブの「CSVを書き出す」で最新のリストをCSVにできます
- アプリの「データ」タブから、手元のCSVを読み込むこともできます
- 学習記録はiPhoneの中だけに保存されます（「データ」タブからバックアップ可能）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体 |
| `words.csv` | 内蔵の単語リスト |
| `sw.js` | オフライン用のキャッシュ |
| `manifest.webmanifest` | ホーム画面に追加したときの設定 |
| `icon-*.png` | アイコン |
